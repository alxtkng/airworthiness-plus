# Security

Airworthiness+ is in private beta. It holds no customer data and has no outside users.

## Reporting a Vulnerability

Contact: `[Security Contact, To Be Confirmed by Alex King]`

Until the contact is confirmed, report through a private message to the repository owner, GitHub `alxtkng`. Do not open a public Issue for a vulnerability.

Include:

- what you found and where (address, endpoint, file or commit)
- the steps to reproduce it
- what an attacker could read, change or stop

## What Happens Next

| Step | Target |
|---|---|
| Acknowledgement | 2 working days |
| First assessment and severity | 5 working days |
| Fix or mitigation for a high-severity vulnerability | Before any further release |
| Credit to the reporter | On request, once fixed |

These targets are provisional for private beta and are reviewed before public beta (`assurance/ncsc-self-assessment.md`, principles 3.2 to 3.5).

## Scope

- In scope: the code in this repository and the service at airworthiness.co once deployed.
- Out of scope: denial of service testing, social engineering, and any system not run by Airworthiness Limited.

Good-faith research within this scope will not be pursued legally.
