# Aircraft damage register and flight report transcription

The Aircraft Record opens both workflows. The supported population for this local trial is UK Part-CAO technical records for Part-ML aircraft. The application stores synthetic exercise data and retains the references used by the operator to find source material.

## Damage register

A drawing record identifies the aircraft, source drawing, revision and view. Enter an outline using whole-number coordinates on a 0 to 100 grid, measured from the top left. For each finding, record the physical frame or zone and dimensions with units. The grid identifies a location on the plotted view. The physical dimensions and frame or zone carry the physical location. Record the source evidence reference, the applicable data and revision, and the disposition. Link an existing defect, repair Work Done record or follow-up programme task when available.

Use the marker or the corresponding text link on the drawing to open the finding. The finding links to that exact marker and to the related work and inspection. A new drawing revision retains the old outline and markers. To remap a marker, open the finding and save a subsequent version using coordinates for the new drawing. The editor carries the previous finding data and links forward for review. Both the original and subsequent records are included in the aircraft export.

The aircraft register refers to the controlled copy of source drawings, approval data and finding evidence held by the operator. The outline stored by Airworthiness+ is a simplified diagram. The evidence field holds a reference to the operator's controlled source. The operator needs that source available when reviewing or transferring the finding.

## Flight technical log

Record a uniquely identified, dated flight using its original flight reference. Open the flight to transcribe a pilot report or a maintenance finding. Enter the source reference, original reporter and wording, then check the attribution and text against the source before saving. Classify the report by ATA chapter and, where available, section, and select the relevant component. The log matches the recorded linked part number exactly, ignoring letter case. Add a link to an existing defect on the same aircraft with the same ATA classification where applicable.

Continuing Airworthiness Managers and Planning and Records staff use the existing Record Defect permission. The session must have recent verification under the existing five-minute policy. The authenticator or passkey prompt verifies the signed-in recorder. A cancel returns to the Dashboard and leaves the report unsaved. The database records the authenticated recorder and name separately from the named source reporter. An identical submission can be retried. A conflicting submission for the same flight, report type and source reference is refused. Neither changes the original.

When the linked defect has been rectified, use **Link an Existing Release** to associate the existing certificate for that rectification. The certificate issuer is shown separately from the original reporter and authenticated recorder. The link records a reference under the existing Record Certificate of Release to Service permission. Transcription supplies provenance and leaves airworthiness decisions and certification in their existing workflows.

## Applicability and sources

- **UK rules.** ML.A.304 requires damage assessment and use of applicable approved repair data. ML.A.305 includes the current status of repairs and deferred maintenance. ML.A.403(d) requires defects unrectified before flight to be recorded and available to the pilot. CAO.A.090 defines CAO record retention and protection obligations. These provisions inform the scope and use of the retained records. [ML.A.304](https://regulatorylibrary.caa.co.uk/1321-2014/Content/Document%20Structure/05b%20ML/2%20Regs/03830_ML.A.304.htm) · [ML.A.305](https://regulatorylibrary.caa.co.uk/1321-2014/Content/Document%20Structure/05b%20ML/2%20Regs/03840_ML.A.305.htm) · [ML.A.403](https://regulatorylibrary.caa.co.uk/1321-2014/Content/Document%20Structure/05b%20ML/2%20Regs/03890_ML.A.403.htm) · [CAO.A.090](https://regulatorylibrary.caa.co.uk/1321-2014/Content/Document%20Structure/05d%20CAO/2%20Regs/06070_CAOA090_Record-keeping.htm)
- **Part-M and AMC context.** For the specified operations, M.A.306 requires additional technical-log content and CAA approval of initial issue. The applicable AMC describes the operational log contents, and subsequent changes follow the applicable approval procedure. This pilot covers database records for the UK Part-ML scope above. [M.A.306](https://regulatorylibrary.caa.co.uk/1321-2014/Content/Document%20Structure/01%20M/2%20Regs/00290_M.A.306.htm) · [AMC M.A.306(a)](https://regulatorylibrary.caa.co.uk/1321-2014/Content/Document%20Structure/01%20M/3%20AMC/AMC%20M%20A%20306%20a%20Aircraft%20technical.htm)
- **Industry references.** ATA Spec 2500 repair and damage status and ATA Spec 2000 Chapter 17 electronic logbook are candidate exchange references. The pilot uses the Airworthiness+ version 1 records export. [ATA standards](https://ataebiz.org/standards/)
- **Airworthiness+ decisions.** Coordinate-based views, immutable revisions, separate attribution and linkage to an existing certificate are local design decisions. Structures engineer and technical records lead review of the mapping and handover, and flight crew and maintenance control review of source transcription and pilot visibility, remain pending. An operator trial would need its source evidence store, agreed transcription and correction procedure, and applicability and approval review.
