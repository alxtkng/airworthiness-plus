# ADR-0013. Tool custody, use and release evidence

Status: Proposed for review, 28 November 2026.

REQ-370 to REQ-373 extend the work package and organisation release workflows. The workshop records a physical handover, inspection, actual use and return as separate events.

- At package issue, pin the applicable maintenance approval and dated reference. Where several approvals are held, require a choice. An already-issued package can receive an evidenced assignment. A later approval change keeps the earlier assignment and prevents prospective use under that reference.
- Issue and use require a current person, site and approval delegation and eligible label controls. Snapshot the bases and completion evidence used. Serialize competing changes on the organisation row to coordinate tool issue, calibration despatch and package release. Enforce one open issue for each physical tool.
- The person reporting prospective use is the technical signer. Keep the package, work card, maintenance-data revision, aircraft identity, actual configuration and signed evidence. A satisfactory inspection can support one use under the matching scope. Preserve unsuccessful inspections and prevent an earlier inspection supplying evidence after a later inspection of the same scope. Later or disputed accounts can be transcribed with the attributed source and evidence gaps.
- A delegated receiver can accept return even when use eligibility has lapsed. The return records destination and condition. An adverse observation restricts the tool until an applicable rectification and reinstatement decision.
- On an organisation release supported by a maintenance authorisation, the existing release transaction checks tool accountability and separate signed physical findings. Clearance includes tools, equipment, extraneous parts and material and addresses removed panels. The release record identifies the certifier and authorisation. The verification links to that release and retains the selected approval and rule. Existing releases and signed historical transcriptions preserve the source evidence.
- Organisation export retains all tooling records. Aircraft exports include linked custody, inspections, claims and verification, with the work-relevant tooling identity and the evidence snapshot. Shared register evidence unrelated to the aircraft remains in the organisation export.

The physical general verification follows the CAA Regulatory Library presentation of CAO.A.060(i) and 145.A.48(c)(1), with the latter consolidated under SI 2023 No. 588. Tool custody records support the organisation's procedure under CAO.A.050 and 145.A.40. CAP 2375 Issue 04 §2.6 provides exposition guidance. Use the current CAE or MOE for delegated signing authority and scope.
